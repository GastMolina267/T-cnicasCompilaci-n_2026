03 / FRONT-END

Léxico y Sintaxis

Definición léxica mediante tokens en mayúsculas y gramática estructurada en minúsculas.

  • Precedencia de Operadores: Ordenada de menor a mayor precedencia en la regla expr para evitar ambigüedades.
  • Escuchador de Errores Personalizado: Hereda de BaseErrorListener de ANTLR para capturar errores léxicos/sintácticos con línea y columna.
  • Visualización de AST: Visualizador interactivo TreeViewer integrado en una interfaz Swing para auditar el parseo.
MiLenguaje.g4 
grammar MiLenguaje;

// Parser Rules (Sintaxis)
programa : unidad* EOF ;
instruccion : declaracion | asignacion | sentenciaIf ;
sentenciaIf : IF PA expr PC instruccion (ELSE instruccion)? ;

// Lexer Rules (Tokens)
IF   : 'if' ;
INT  : 'int' ;
ID   : [a-zA-Z_][a-zA-Z0-9_]* ;
INTEGER : [0-9]+ ;
WS   : [ \t\r\n]+ -> skip ;

05 / CÓDIGO INTERMEDIO

Código de Tres Direcciones (TAC)

Traducción lineal y plana del AST. El código resultante representa instrucciones elementales basadas en operandos y destinos temporales.

Variables Temporales

Autoincrementales (t1, t2, ...) creadas en expresiones complejas.

Saltos y Control de Flujo

Etiquetas (L1, L2, ...) en combinación con instrucciones IF cond GOTO L y GOTO L.

Estructuras de Pila para Control

Pilas en CodigoVisitor para asociar dinámicamente sentencias break y continue con las etiquetas del bucle activo.

Traducción a TAC
C++ original
int x;
x = 5 + 3 * 2;
TAC Generado
DECLARE x int
t1 = 3 * 2
t2 = 5 + t1
x = t2
06 / OPTIMIZACIÓN

Optimizador Multipaso

Limpieza y simplificación del código intermedio mediante pasadas secuenciales.

Bucle de Punto Fijo

Las optimizaciones se ejecutan recursivamente en un bucle while. Dado que el plegado de constantes puede habilitar propagaciones y simplificaciones adicionales, se optimiza continuamente hasta que una pasada no produzca cambios o se llegue a un límite de 10 pasadas.

Seguridad ante Saltos

Para evitar propagaciones erróneas de constantes al cruzar saltos o bucles, el optimizador limpia completamente la memoria de constantes conocidas al encontrar cualquier instrucción LABEL o FUNC_START.

07 / TÉCNICAS

Detalle de Optimizaciones

Técnicas implementadas e integradas linealmente en el motor.

Plegado de Constantes

Evalúa operaciones constantes en tiempo de compilación.
t1 = 5 + 3 ➔ t1 = 8

Propagación de Constantes

Reemplaza lecturas de variables con constantes conocidas.
x = 8; y = x; ➔ y = 8

Reducción de Fuerza

Reemplaza multiplicaciones por 2 con sumas de sí mismo.
x * 2 ➔ x + x

Eliminación de Código Muerto

Descarta líneas inalcanzables tras un return/goto y limpia temporales no leídos.

08 / PRUEBAS

Caso de Optimización Práctico

Resultado del análisis sobre ejemplo_optimizacion.txt

1. Código C++

int main() {
  int x, y, z, dead;
  x = 5 + 3;
  y = x * 1;
  z = y + 0;
  return z;
  dead = 999;
}

2. TAC Original

func_main:
  DECLARE x, y, z, dead
  t1 = 5 + 3
  x = t1
  t2 = x * 1
  y = t2
  t3 = y + 0
  z = t3
  return z
  t4 = 999
  dead = t4
  return

3. TAC Optimizado

func_main:
  DECLARE x, y, z, dead
  x = 8
  y = 8
  z = 8
  return 8
Métricas de reducción: Instrucciones eliminadas: 6 Reducción de código: 26.67%
09 / CONCLUSIONES

Lecciones y Conclusiones

Beneficios clave obtenidos durante el diseño e implementación del compilador.

1

Arquitectura Altamente Desacoplada

La combinación de ANTLR4 con Visitors individuales e independientes para el análisis semántico y la generación de código TAC garantizó un mantenimiento de código extremadamente simple.

Eficiencia de Optimización Multipaso

El enfoque de Punto Fijo demostró ser la mejor técnica para manejar optimizaciones interdependientes, logrando reducciones significativas de variables y código intermedio.
